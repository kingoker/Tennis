# Amina Nurmukhan — спонсорское портфолио

Спонсорская презентация теннисистки Амины Нурмухан (Казахстан, ITF No. 389 на 12.10.2026) на чистых HTML, CSS и JavaScript. Без фреймворков и без сборки.

## Как это устроено

Вся презентация — **одно большое полотно**: теннисный корт в масштабе, вид сверху (1 м = 300 px). Семь разделов лежат на корте как листы, а камера летит от листа к листу по траектории мяча. Каждый следующий раздел — на другой стороне сетки, как в розыгрыше.

Фильм идёт сам: каждая глава держится **1 минуту**, потом камера плавно перелетает к следующей. После последней главы (контакты) фильм останавливается. Таймкод внизу идёт в реальном времени, полоса глав заполняется по мере просмотра. Прокрутка или стрелки перехватывают управление в любой момент, и фильм продолжается с того места, где читатель остановился. Пока вкладка скрыта, фильм на паузе. Длительность главы — `CHAPTER_MS` в `script.js`.

Палитра — национальная казахская: небесно-голубой (#00AFCA) и солнечное золото (#F6C21C) флага, кремовый цвет войлока (#F3EAD6) для текста, глубокий синий ночной степи (#0E3446, #06202D) для кадров и полос, красный (#C8102E) только в мелких акцентах. Кинополосы, обложку и корт обрамляет орнамент «қошқар мүйіз» (бараньи рога), как кайма сырмака.

Подача — как у документального фильма: кинополосы сверху и снизу, в нижней — таймкод и полоса глав; зерно плёнки и виньетка; фото печатаются в ч/б и «проявляются» в цвет, когда камера прилетает к кадру; цитата игрока — субтитр, контакты — финальные титры. Шрифт один, Archivo: узкий жирный для заголовков, обычный для текста.

Это **документ для спонсоров, а не сайт**: в нём нет кнопок, меню, фильтров и форм. Кинополосы только показывают, где читатель находится. Разделы: обложка, профиль, рейтинг и достижения, результаты, цели, расписание и бюджет, контакты. Блока со спонсорскими пакетами и ценами нет.

| Режим | Когда включается | Как работает |
|---|---|---|
| **Полотно, большой экран** | окно ≥ 960×560 | Листы 1440×900 лежат на корте, камера перелетает между ними. Прокрутка двигает камеру; длину странице даёт невидимая дорожка. |
| **Полотно, телефон** | окно уже 960 или ниже 560 px | Тот же фильм: листы в ширину экрана выложены парами на вертикальном корте, камера перелетает между ними через сетку, а по длинным листам медленно панорамирует сверху вниз (несколько кадров на главу, минута делится между ними). |
| **Страница** (page) | `prefers-reduced-motion` или параметр `?view=page` | Листы идут друг за другом как обычная страница, без автопроигрывания. |
| **Печать** | Cmd/Ctrl + P | Каждый лист — отдельная альбомная страница 1440×900. |

Как читать в режиме полотна (видимых элементов управления нет):
- ничего не трогать — фильм идёт сам, минута на главу;
- колесо, трекпад или свайп — полёт между кадрами; если остановиться посреди перелёта, камера сама мягко доедет до ближайшего кадра;
- стрелки, `Space`, `PageUp`/`PageDown`, `Home`/`End` — предыдущий / следующий / первый / последний лист;
- клик по затемнённому соседнему листу — перелёт к нему;
- для показа на экране — полноэкранный режим браузера (Ctrl + Cmd + F на Mac, F11 на Windows).

## Запуск локально

Сборка не нужна. Можно просто открыть `index.html` в браузере, но лучше через локальный сервер:

```bash
cd tennis-portfolio && python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Положите содержимое папки `tennis-portfolio/` в корень репозитория (или в `/docs`).
2. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**, выберите ветку `main` и папку `/ (root)` (или `/docs`).
3. Через минуту сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

Все пути относительные, поэтому сайт работает и из подпапки репозитория. После публикации обновите `og:title`, `og:image` и `<title>` в `index.html`.

## Плейсхолдеры: что подтверждено, а что нет

Любое неподтверждённое значение в `data.js` обёрнуто в `TBD(...)`:

```js
nationality: TBD("Nationality"),   // на странице с золотым пунктирным подчёркиванием
nationality: "Portugal",           // подтверждено, показывается обычным текстом
```

Длинные тексты-образцы (биография, мотивация) помечаются ярлыком **Sample copy**. Строки результатов с `example: true` помечены **Example** и не входят в статистику. Когда всё заменено, поставьте `settings.showPlaceholderMarks: false`.

## Как поменять…

### Имя и рейтинг
`data.js` → `player.firstName`, `player.lastName`, `player.initials`, `player.highlight` (строка на обложке), `ranking.current`, `ranking.date`, `ranking.category`. Шесть цифр на листе рейтинга задаются массивом `rankingStats` (`{ label, value }`). Заголовок вкладки обновится сам. Мета-теги `<title>` и `og:*` в `index.html` поменяйте вручную: их читают поисковики и соцсети.

### Фотографии
`data.js` → `images`. Для каждого слота (`cover`, `profile`, `goals`, `contact`):

```js
cover: { src: "assets/images/cover.jpg", alt: "…описание…", sample: false }
```

Пока `sample: true`, на фото видна подпись «Sample photo, not the player», чтобы стоковый спортсмен не выдавался за игрока. Сейчас стоят фото с Unsplash (бесплатная лицензия Unsplash). Для URL Unsplash адаптивный `srcset` строится автоматически. Для своих файлов хватит изображения шириной около 2000 px. Если фото не загрузилось, лист остаётся читаемым.

### История рейтинга (график)
`data.js` → `rankingHistory`: `{ date: "2025-06", rank: 471 }`, от старых к новым. График строится только по реальным данным. Пока точек меньше двух, графика в документе нет — справа остаётся только список достижений.

### Результаты турниров
`data.js` → `results`. Одна строка — один турнир:

```js
{ date: "2026-09-14", tournament: "M25 …", country: "…", surface: "Clay",
  category: "M25", round: "QF", result: "L 4–6 6–3 5–7" }
```

Результат, начинающийся с `W ` или `L `, выводится как победа или поражение. Дату можно указать как `"2023-09-14"` или `"2023-09"`, неизвестную — как `TBD("Add date")`, такие строки идут в конец. Сезонный баланс задаётся отдельно в `winLoss: { wins, losses, season }` и показывается, только если он указан. Лучший результат — поле `bestResult`. На телефоне таблица превращается в карточки.

### Бюджет
`data.js`:
- `schedule` — турниры со сметой `travel`, `accommodation`, `entry`, `other`;
- `annualCosts` — годовые статьи (тренер, фитнес, экипировка, прочее);
- `funding.confirmed` — реально подтверждённое финансирование (держите `0`, пока нет подписанного договора);
- `funding.sponsorshipTarget` — цель спонсорства (`null` = равна оставшемуся дефициту);
- `settings.currency` / `settings.locale` — валюта и формат чисел.

Перелёты, проживание и взносы суммируются из расписания. `other` по турнирам добавляется к статье «Other documented expenses». Итог, дефицит и доли считаются автоматически. Проверить расчёт можно в консоли: `computeBudget(PORTFOLIO)`. Все суммы на странице подписаны как оценки.

### Контакты
`data.js` → `contact`. Пустые поля в документ не попадают. Как только задан `itfProfile` (полный `https://` URL), в карточке контактов появляется QR-код: библиотека `qrcode-generator` подгружается с cdnjs только в этом случае. Email и телефон в документе — кликабельные ссылки.

## Экспорт в PDF

1. Нажмите Cmd/Ctrl + P.
2. Получатель: **Save as PDF**.
3. В «Дополнительных настройках» включите **Background graphics** (фоновые изображения), иначе пропадут тёмные фоны.
4. Поля: **None**. Размер страницы задан в CSS (1440×900, альбомная), Chrome подставит его сам.

Получится 7 страниц, по одной на раздел. Кинополосы и зерно в печать не попадают. PDF не создаётся автоматически, его сохраняет браузер.

## Типографика

Шрифты рассчитаны на чтение без усилий:
- засечный Cormorant Garamond используется только в крупных заголовках (от 34 px, начертание 500–600);
- весь остальной текст набран Manrope: основной текст 19–22 px, таблицы и списки 17 px, подписи не меньше 15 px;
- подписи набраны обычным регистром и полужирным, без мелких разрядок капсом;
- камера кадрирует лист почти на весь экран, поэтому на ноутбуке 1440×900 текст выглядит почти в натуральную величину.

## Доступность и производительность

- Семантические заголовки, `<dl>` для фактов, `<table>` с `caption` для таблиц, `aria-live` для текущего раздела.
- Видимый фокус, диалог на `<dialog>` с ловушкой фокуса и возвратом фокуса. При переходе Tab в другой лист камера летит туда.
- `prefers-reduced-motion` включает режим страницы без анимаций.
- Анимации только через `transform` / `opacity`. Цикл `requestAnimationFrame` работает лишь во время движения камеры и останавливается в покое. `will-change` снимается в покое, чтобы текст оставался чётким.
- Нет трекеров и аналитики. Внешние ресурсы: Google Fonts, фото Unsplash и (по требованию) QR-библиотека.
